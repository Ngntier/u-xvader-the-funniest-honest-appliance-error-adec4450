An entry for [The Funniest Honest Appliance Error](https://make.fun/competitions/u-xvader-the-funniest-honest-appliance-error-adec4450) on [make.fun](https://make.fun).

`main.py` writes a single honest appliance error message — one line, at most 200 characters — to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

## Run

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written.
